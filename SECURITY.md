# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting
on this repository ("Security" tab, "Report a vulnerability").

We aim to acknowledge a report within 3 working days and to give a first
assessment within 10. We will keep you informed until a fix is released and
credit you unless you prefer otherwise.

## Supported versions

No version has been released yet. Once releases begin, the latest minor
release receives security fixes.

## Scope

In scope: the node, the admin, the CLI, the UI, the published images and the
Helm chart. The threat model, once written, lives in `docs/ops/threat-model.md`.
